Connect an agent

Give Claude (or any MCP-speaking agent) read/write access to your Cairn workspace — the same auth as you, scoped and revocable.

◆ MCP available now

Add Cairn as an MCP server in your client. It's OAuth 2.1 (code + PKCE) — no static API keys to copy around.

  1. Add {{.BaseURL}} as an MCP server in your client (e.g. Claude Desktop, Claude Code).
  2. Your client discovers the OAuth authorization server at {{.BaseURL}}/.well-known/oauth-authorization-server.
  3. You approve the three scopes once, via Pocket ID:
    • artifacts:read — read artifacts you can access
    • artifacts:write — create & push new artifacts
    • annotations:write — comment & react on your behalf
  4. The client talks to {{.BaseURL}}/mcp — reading, pushing, commenting, and reacting as you.
