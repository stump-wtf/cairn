Operator console

You run this instance. This console bounds tenant data and never reads it: it shows who has an account and how much they store, and lets you suspend an account. It never shows an artifact's title, body, link, tags or comments, and being an operator does not let you open anyone else's artifacts.

Whoever controls the database and the object store can still read everything in them. This console removes the easy path and records what you do here; it does not pretend to more.

Users

Suspending a user signs them out everywhere at once: their browser sessions, API tokens and OAuth grants (with every access and refresh token) stop working on their next request, and they cannot sign in until you reinstate them. Reinstating restores nothing; they sign in again. Every action needs a reason, which the user can read on their Settings page.
