>_ CLI available now

The cairn CLI is a single Go binary — a REST client of this same API, no domain logic of its own.

  1. Install: see the cairn CLI guide.
  2. Mint a token above, then cairn login --token <token>.
  3. cat report.md | cairn — pipe or pass a file in, get a shareable link back.
  4. cairn add a.png b.log dump.sql — push several files as one bundle.
