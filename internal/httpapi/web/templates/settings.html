◆ MCP connection available now

Give Claude (or any MCP-speaking agent) read/write access to your Cairn workspace — the same auth as you, scoped and revocable.

It's OAuth 2.1 (code + PKCE) — no static API keys to copy around.

  1. Add {{.BaseURL}} as an MCP server in your client (e.g. Claude Desktop, Claude Code).
  2. Your client discovers the OAuth authorization server at {{.BaseURL}}/.well-known/oauth-authorization-server.
  3. You approve the three scopes once, via Pocket ID:
      {{range .ScopeOptions}}
    • {{.Value}} — {{.Label}}
      • {{end}}
  4. The client talks to {{.BaseURL}}/mcp — reading, pushing, commenting, and reacting as you.

>_ CLI coming in v0.0.3

The cairn CLI is in progress — tracker #20–#22. The shape it's landing in:

  • cairn login authorize once over MCP OAuth — same auth as your agent
  • cat report.md | cairn pipe or pass a file in, get a shareable link back

Not installable yet — no install command exists until v0.0.3 ships. Check back once #20–#22 close.
